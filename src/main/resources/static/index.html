第一次使用？了解启动与模型配置

需要 Java 21 和 Maven。在项目目录设置 APP_ACCESS_TOKEN 后运行 mvn spring-boot:run，默认地址为 127.0.0.1:8088，请从该地址打开页面。

默认本地词项哈希检索，不是语义向量。可选设置 CHAT_API_BASE_URL、CHAT_API_KEY、CHAT_MODEL 启用生成；设置对应的 EMBEDDING_* 三项启用语义向量。BASE_URL 通常以 /v1 结尾。

更换向量模式或模型后，请新建库或重新导入资料。模型密钥仅设置在后端环境变量中，不要在此输入。扫描 PDF 暂不支持 OCR；这是本地学习工具，不应直接暴露公网。
